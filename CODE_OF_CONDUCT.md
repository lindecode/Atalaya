# Código de conducta

Atalaya busca una comunidad técnica respetuosa, segura y profesional.

## Comportamiento esperado

- Tratar a las demás personas con respeto y paciencia.
- Criticar ideas y código, no personas.
- Proteger información privada, credenciales y datos de telemetría.
- Informar vulnerabilidades mediante el canal privado descrito en
  [SECURITY.md](SECURITY.md), no en incidencias públicas.
- Aceptar decisiones de mantenimiento documentadas aunque exista desacuerdo.

No se toleran acoso, discriminación, amenazas, publicación de datos privados ni
el uso de los canales del proyecto para distribuir software malicioso.

## Aplicación

Los mantenedores pueden editar o retirar contenido, rechazar contribuciones y
limitar la participación cuando sea necesario para proteger a la comunidad o al
proyecto. Los incidentes deben comunicarse de forma privada a los mantenedores
mediante los canales del repositorio.

Este documento gobierna los espacios administrados por el proyecto; no sustituye
las leyes aplicables ni los términos de un contrato comercial.
